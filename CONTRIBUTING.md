# Contributing to LaclauGPT

Thank you for your interest in contributing to **LaclauGPT**.

LaclauGPT is an open research framework for **LLM-assisted computational social science and discourse analysis**. It combines computational methods, social-science theory, human interpretation, and reproducible research infrastructure.

Contributions are welcome from social scientists, data scientists, developers, designers, digital-methods researchers, NLP/LLM researchers, network scientists, and others interested in building transparent and human-in-the-loop tools for social research.

The project is intentionally modular. Before opening a pull request, please make sure your contribution belongs in the correct repository.

## Project structure

LaclauGPT currently consists of a meta-repository and three independently deployable modules.

### LaclauGPT

Repository:

`TomiToivio/LaclauGPT`

This is the **meta-repository** and main entry point.

Contribute here when changing:

* the scientific paper
* theory and methodology
* project-wide architecture
* canonical data contracts
* interoperability specifications
* privacy and research-ethics guidance
* full-system installation documentation
* cross-module design decisions
* project-wide examples and documentation

Do not place normal executable Collection, Analysis, or Visualization implementation code in the meta-rep
