language scope has to be stated as `en` with `fi` as an aspiration. This is evidence added to
**#294**, not a new issue: the same defect, now measured per arena.

  Argumentation" (Apaf)** (Vasileiou & Derendiaeva). Operationalises **critical

  published 19-20 Oct). Models discourse as **an interlinked argumentation network over
