## 4. Scientific research watch

From today's arXiv scan (cs.CL/cs.SI, November window), four items worth the
register; none change the locked Phase 1 framework:

- **arXiv 2611.31532 (Bafna, MacComas, Bader, Gligorić): "Can LLM-Simulated
  Respondents Pre-Test Survey Questions?"** — a *preregistered, prospective*
  validation design: model predictions are committed before the target human
  responses exist, ruling out memorization by construction. Why it matters:
  this is the cleanest available template for AI26's own validation run — any
  LLM-assisted coding proposal can be committed before the human-verified
  subset is opened, which converts our "LLM outputs are preliminary
  evidence" protocol into a falsifiable, pre-registered comparison. Phase 1
  validation design (comparator beside 2610.35179's screen), Phase 3 method.
- **arXiv 2611.24383 (Bazaid & Zubiaga): "What Majority Labels Hide"** —
  per-item annotator disagreement preserved (3 annotators/dialect), models err
  most on contested cases, hard-label training hides them. Aligns directly
  with the project's claim-status/attribution preservation: disagreement is
  evidence, not noise to be collapsed by majority voting. Phase 1
  methodological support, Phase 2 relevance for contested-case coding.
- **arXiv 2611.29765 (Yeste, Greco, Rosso, Tagarelli): LLM personas as
  synthetic audiences reading the leaders' X posts ahead of Spain's 29N
  election** — speaker attribution matters: naming any leader lowered support
  for identical text (Abascal's penalty nearly twice the average), so persona
  responses react to *who speaks*, not only *what is said*. Phase 2 watch:
  reception-side LLM simulation is a different method family from AI26's
  actor-coding, but the source-cue result is a caution for any persona-based
  reading of elite discourse.
- **arXiv 2611.28812 (Liu, Arana-Catania, Orchard): "The Humming Revachol"** —
  dialogue network analysis of Disco Elysium's 73-character mention network;
  narrative power operationalised as attention, authority, discursive
  initiative and embeddedness. A curiosity with a usable edge: "discursive
  initiative" is a candidate Phase 2 edge-type/actor-level measure worth a
  line in the Phase 2 design notes, and the paper is a compact DNA
  demonstration outside political corpora.

No new 4CAT, Zeeschuimer or DATS release surfaced in this scan; no migration
recommended.
