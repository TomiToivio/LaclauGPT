### New finding: the elites "blogs and manifestos" layer is one document - issue #321

Paper §4.1 names "manifestos, blogs, interviews, podcasts, forums, and public social media posts" as
elite material, and the elites arena's first `sampling_focus` is `frontier-lab and industry
discourse`. On the analysis-grade corpus that layer is **1 record out of 1,962 (0.05%)**.

Root cause, verified in the code and then against the store: `ai26_laskin_runner.py:287-316` gives a
`web_source` dated articles **only** if its homepage is a key of `_WEB_SOURCE_FEED_FALLBACKS`, a
two-entry map (`openai.com/news`, `microsoft.com/en-us/ai/blog`). Every other row falls through to a
single homepage snapshot via `fetch_web_child()`, which has no publication time and is therefore
handed off as `excluded / missing_source_publication_time`. The policy keys
`fetch_external_links_as_web_sources: true` / `link_fetch_failure_blocks_parent: false` are honoured
only in `capture_server.py:378-401`, i.e. only on the browser path this node never runs.

All twelve non-fallback rows hold exactly one record ever, zero in 14 days, while the pages answer
200 with 22-301 anchors from Laskin (table with per-source anchor counts in #321). Ruled out: bot
blocking of the #219 kind, transient network failure, and a parsing fault - except for
`deepmind.google/discover/blog/`, which serves 0 anchors (JS-only) and genuinely needs the feed route.
