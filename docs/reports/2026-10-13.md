and carried into `main` by PR #179.

  real newline (same expression, reformatted over multiple lines; empty frame still
  returns `[]`), plus `Mapping` moved to `collections.abc` because CI lints *changed*
  Python files with `ruff check` and this pre-existing `UP035` finding would otherwise
  re-redden the lint job for any PR touching the file.
  Verified locally (repository venv, Python 3.11.17, ruff 0.16.8, pytest 8.4.2):
  `compileall` exit 0; `ruff check` on the file clean; **`pytest tests/` 399 passed**
