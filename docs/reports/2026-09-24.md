Power, labour, ownership, inequality, infrastructure, governance and exclusion remain central questions, but technological change is not assumed in advance to be either emancipatory or oppressive. PCM can remain nearby conceptual inspiration; PCM-specific metaphysics and political theory stay outside locked Phase 1 unless the Phase 1 manuscript itself introduces them.

### Methods watch: two newly surfaced preprints not previously covered

- arXiv:2609.11109 (10 Sep), *How AI Coders Discuss, Disagree, and Reach
  Consensus*: multi-agent LLM coding where agents code independently, debate
  and reconcile. Coding accuracy is mediated by codebook length, data
  similarity and agent disagreement; notably, intense unresolved agent debates
  preceded higher accuracy, while LLMs emulate human discussion behaviour
  without adaptive contextual responsiveness. For the Phase 1 validation pilot
  this supports treating LLM disagreement rates as a diagnostic routing signal
  to human review rather than as noise — while keeping the locked
  human-in-the-loop protocol as the final arbiter.
- arXiv:2609.06664 (6 Sep), *EviMap*: evidence-grounded hierarchical topic
  maps for unlabeled corpora, built around auditable thematic overviews. Its
  sharpest point is that the first thematic map shapes what users notice and
  carry into downstream analysis, so overview artefacts must be verifiable.
  That is the same first-map bias the pre-analysis design already guards
  against. Interesting reference for future Visualization exploration views;
  not a reason to add machinery during Phase 1 convergence.
