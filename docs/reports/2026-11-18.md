### Root cause, ruled out again from this machine

(`ECONNREFUSED`, not a timeout), while the *same host* accepts connections on its Redis port and
the analysis preflight reports `"redis": {"reachable": true}` alongside
`"problems": ["mongodb unavailable: ServerSelectionTimeoutError"]`. So: host up, network path
open, nothing listening on the store port — `mongod` is not running or its port is closed. Still
not a credential failure (a refused connection never reaches authentication), still no local
fallback (Laskin's own instance rejects the AI26 credentials at authentication), and still not
restartable from here — the wrappers fail fast and deterministically, so a local restart changes
nothing.
