### Root cause of the missing end line (diagnosed, fixed this run)

The collect wrapper runs under `set -e`, and the runner returns exit 1 whenever any
source records an error. A transient arXiv error therefore marks the tick
`partial`, returns non-zero, and aborts the wrapper **before** its
`AI26 Laskin collection end` echo. Data is still collected; only the log's
end-marker and the wrapper's exit status are affected.

### Issue worked: #212 (Data-Collection) - arXiv retry policy never applied

Worked and advanced to a PR. The study config declares
`collector_defaults.retry` (max_attempts 3, 2s -> 30s backoff) but only
`PluginRunner` read it; the AI26 Laskin runner drives collectors directly, so the
arXiv collector ran the library's fast internal retry with no backoff and then
gave up, costing a whole tick's scholarly records.

Fix (PR #216, branch `issue-212-arxiv-bounded-retry`, base `7b3f6e8`): a bounded
retry at the orchestration boundary - `load_collector_retry_policy()` reads the
declared policy with conservative fallbacks; `_call_with_retry()` applies
`RetryPolicy.delay_for` backoff and retries only 429/500/502/503/504, re-raising
anything else. Verification: 6 new tests pass, full suite 447 passed, `ruff check`
clean, contracts green, PR CI fully green.

Note: the PR's first CI run caught a real bug in the fix - `requests` was imported
unconditionally in the status check but is only present via the optional
`documents` extra, while CI installs `.[dev]` alone. Made the import defensive and
added a regression test that simulates `requests` being absent.

### Scientific research watch (evening scan)

- **Timoneda, "Auditing Political Alignment in LLM Assistants: Engagement,
  Stance, and User Identity" (arXiv:2609.23039, submitted 19 Sep 2026;
  surfaced in search this run).** Preregistered 7,500-conversation audit of
  six AI systems introducing "speech regimes" — policies over whom to
  answer, what to say, and whether to engage, conditional on topic and
  inferred user identity. Refusal is treated as an outcome, not missing
  data. Findings: on the zero-stakes control every system accommodates the
  user (political restraint is a policy, not principle); on contested topics
  the systems split into five distinct regimes (GPT mirrors every user on
  abortion; Gemma refuses all; Claude selectively engages
  strong-conservative users; Grok accommodates conservatives only); systems
  infer users' ideology, so accommodation spills over across topics; and a
  two-version Grok comparison shows the regime *changing between releases*
  in a way static audits miss. *Credible (preregistered, human-validated
  2-judge scoring; single author).* Why it matters to LaclauGPT: (a) it is
  a fully worked example of audit-as-discourse-analysis where the subject
  is an articulating agent — the same object the paper's §2/§3 machinery
  is built to describe, here with refusal-as-nodal-silence operationalised;
  (b) the speech-regime typology is a candidate Phase 2 vocabulary for
  modelling *AI agents as communicating actors* (the framework must handle
  hybrid networks with LLMs/AI agents, and this paper is the first
  preregistered instrument this watch has seen for behavioural regime
  classification of exactly those actors); (c) its LLM-judges-validated-
  against-human-coding design is directly reusable for AI26 validation
  design, and its version-comparison finding motivates logging model
  revisions per analysis window. Phase 2 (vocabulary candidate), Phase 4
  (related-work capture).
- **PoliticalNLP 2026 @ LREC (16 May, Palma) proceedings surfaced in search

  Streams to Narrative Intelligence Briefs: LLM-Assisted Political
