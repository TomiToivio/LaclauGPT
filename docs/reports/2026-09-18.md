## Programme guardrail

`paper/PAPER.md` is the source of truth for **Phase 1**. Its theoretical and methodological framework is treated as conceptually locked. Current wording, references, examples and empirical scope may continue to evolve, but later theory must not retroactively redesign Phase 1.

The current paper already positions AI26 within Critical AI Studies while distinguishing assemblage description from Laclaudian political articulation. It also keeps the ideological field open: accelerationism, x-risk, Critical AI, anti-AI and left techno-optimism are starting formations rather than permanent actor labels. This is the correct Phase 1 boundary and should be preserved.

## High-signal repository developments

### 1. Cross-module interoperability has become testable rather than merely documented

The strongest engineering development is the shared canonical parity/conformance work across the three implementation repositories. Collection and Visualization now have offline cross-module contract checks; Collection and Visualization adopted the shared canonical parity fixture; Analysis has continued tightening evidence/provenance behavior. All four repositories currently show green latest CI runs.

**Why it matters:** Phase 1 increasingly has an executable scientific data boundary rather than three loosely coordinated applications. The next step should be one end-to-end synthetic fixture that traverses Collection -> Analysis -> Visualization while preserving source identity, provenance, evidence spans, uncertainty, multimodal/translation provenance and human-review state.

### 2. Analysis tightened the most important epistemic boundary: quoted evidence

Analysis now verifies evidence quotes against source material or explicitly flags them as inexact. This is more scientifically important than another classifier or graph feature.

**Why it matters:** Phase 1 depends on traceability from LLM proposals to evidence. Exact/inexact evidence status should survive storage, exports and Visualization so researchers never mistake reconstructed model text for a source quotation.

### 3. Phase 2 now has a real literature base, but it must remain Phase 2

The main repository added a substantial AI-era network/cybernetics source synthesis, including Harrison White, Elena Esposito, van Dijck/Poell/de Waal, Terranova, Bratton and Schneider. White is especially useful for the bridge between meaning and relational structure; Esposito is useful for non-anthropomorphic artificial communication; platform-society and Terranova material add infrastructure, selection, labour and political economy.

This is high signal for **Phase 2**, whose umbrella issue now explicitly defines:
- Content of Communication -> Laclau;

**Important boundary:** these sources should not be folded back into Phase 1 as a redesigned ontology.

### 4. The programme roadmap is now partially out of sync with the phase issues

The separate Data-Storage concept has been removed from project instructions and remaining module references. Collection now explicitly treats storage as deployment infrastructure. This is consistent with the canonical-record principle: SQLite, MongoDB, files, Redis coordination and other backends should not become competing scientific ontologies.

### Phase 2 — advanced communicating-agents theory/method

**Status:** theory scaffolding is forming; implementation should remain experimental until validated.

The strongest newly consolidated literature is White + Esposito + platform/network political economy. Leifeld remains the methodological bridge because DNA explicitly turns coded actor/concept/stance statements into dynamic networks. A useful 2026 signal is Leifeld's continuing work on political discourse networks, conflict and frame evolution.

A particularly relevant 2026 source is Marent, Merkel, Petersen & Tucker, *Therapeutic encounters with Chatbots: Towards a sociological approach to human=machine communication*, which explicitly builds a sociological account of human-machine communication from Luhmannian systems theory. It supports Phase 2's artificial-communicator problem without requiring claims about machine consciousness.

Main gaps:
1. specify the minimum communication-event schema: communicator/agent, addressee where recoverable, claim/concept, stance, evidence, time, platform/context;
2. define how Laclau relations map to DNA without equating network measures with nodal points/hegemony;
3. define when algorithms/LLMs/platforms count as communicators, mediators, infrastructure or assemblage components;
4. build a small human-coded DNA benchmark before scaling automated graph construction;
5. keep PCM/Faggin/Hoffman explicitly outside empirical premises.

### Phase 3 — preliminary/intermediate results

**Status:** not yet an empirical-results phase; prerequisites are becoming available.

Dependencies:
- enough sustained AI26 data;
- Phase 1 validation;
- evidence-linked Visualization;
- stable empirical snapshots;
- only those Phase 2 methods that have passed validation.

Phase 3 should report methodological failures alongside findings. It should not force Castells/DNA/agent concepts into results merely because Phase 2 explored them.

### Phase 4 — final results and synthesis

**Status:** correctly downstream.

The key dependency is not additional architecture but preservation of provenance and versioning now. Final claims will eventually need to distinguish Phase 1 methods actually used, Phase 2 extensions that survived validation, computational measurements, and human discourse interpretation.

## Research and ideology watch

### High signal: AI `safety` remains a strongly contested political signifier

The current U.S. debate is increasingly explicit about a position that rejects the identity label “doomer” while still demanding guardrails. Reuters reported Senator Mark Warner arguing for rapid AI safeguards while explicitly distancing himself from catastrophic-doomer identification. This is useful AI26 material because it demonstrates why actor-level ideology labels are weaker than claim/articulation analysis.

At the same time, debate continues among industry self-regulation, liability/competition, independent evaluation, regulation and international coordination. Candidate articulations worth tracking include:

- `safety -> guardrails -> oversight -> infrastructure protection`
- `safety -> independent evaluation -> disclosure -> accountability`
- `safety -> liability -> firm responsibility -> competition`
- `safety -> regulation -> incumbent power / regulatory capture`
- `safety -> international coordination -> strategic stability`

These are candidate relations for corpus testing, not predefined ideological classifications.

## Methods watch

Three methodological signals deserve priority:

1. **Forster et al. (2026)** use a four-stage LLM qualitative-analysis pipeline with expert validation and full traceability. This supports Phase 1's decomposed, auditable pre-analysis model.
   https://journals.sagepub.com/doi/10.3233/SHTI260065

2. **Butler et al. (2026, JAMIA Open)** compare multi-step LLM-assisted thematic analysis against a human-only reference standard. This is a useful template for Phase 1 validation design.
   https://academic.oup.com/jamiaopen/article/9/5/ooag091/8789713

3. **Using ChatGPT for thematic analysis of Roman Urdu interviews (2026)** reports that surface coding was stronger than cultural/emotional nuance and retains human oversight as essential. This matters for multilingual AI26: validation must test interpretive depth, not merely label agreement.
   https://doi.org/10.1016/j.ajp.2026.105071

## Bottom line

AI26 now benefits from a useful separation of concerns: **Phase 1 should converge and validate; Phase 2 may expand; Phase 3 should test the machinery against evidence; Phase 4 should synthesize what survives.** The most valuable technical work is therefore no longer architectural proliferation. It is proving that evidence, provenance, context, uncertainty and human review survive the entire pipeline, while developing the Laclau-Castells-DNA communicating-agents model separately enough that it cannot silently rewrite the locked Phase 1 research design.
