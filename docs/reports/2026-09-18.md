## Four-phase status

### Phase 1 — research plan + technical implementation

**Status: converging.** The paper has a stable conceptual core; cross-module contracts and evidence provenance are improving; the prompt-stack refactor can make methodological/context boundaries more explicit.

**Gaps:** (1) end-to-end provenance fixture; (2) human-coded multilingual validation corpus; (3) evidence/provenance drill-down in Visualization; (4) reproducible empirical snapshots; (5) sustained AI26 empirical execution; (6) a test ensuring context/memory cannot override the locked Phase 1 constitution.

### Phase 2 — communicating-agents theory/method + implementation

**Status: theory scaffolding is strong enough to begin minimal operational specification.** Do not add another large theoretical layer yet. Specify the smallest communication/DNA event model: communicator/agent, addressee where recoverable, claim/concept, stance/relation, evidence, time and platform/context. Then benchmark LLM extraction against human DNA coding before scaling network construction.

A useful theoretical constraint remains: network metrics are not computational substitutes for Laclaudian nodal points, hegemony or equivalence. DNA bridges coded discourse and actor networks; it does not collapse one ontology into the other.

### Phase 3 — preliminary/intermediate results

**Status: prerequisites are forming, but empirical-result claims are premature.** Dependencies are sustained AI26 data, Phase 1 validation, evidence-linked visualization, stable snapshots and only those Phase 2 extensions that survive validation. Methodological failures and negative results should be reportable outputs.

### Phase 4 — final results and synthesis

**Status: downstream.** The important present-day dependency is provenance/versioning. The final paper must be able to distinguish locked Phase 1 methods actually used, validated Phase 2 extensions, computational measurements and human interpretation.
