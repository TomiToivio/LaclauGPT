### Issue worked on: #426 -> PR #427

Root cause of the remaining backfill rejections: #352 taught `normalize_schema_version` to
fold undeclared `source` keys into `source.extensions`, but the distributed worker's
handoff loader validated the MongoDB row with `CanonicalRecord.model_validate` directly and
never ran the fold. Records carrying `source.backfill` therefore went terminal at seed with
`Extra inputs are not permitted`.

PR #427 exposes the fold as `preserve_undeclared_source_keys()` and uses it in the loader,
with a regression test built from the failing shape (source platform, language,
`raw_metadata` preserved; the stored row is not mutated; records without extensions are
unchanged). Verified on Laskin: full test suite passes, contract checks pass; PR CI
is green (tests on 3.11/3.12/3.13, changed-file lint, CodeQL).
