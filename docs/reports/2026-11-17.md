### Root cause and what was ruled out

The configured AI26 MongoDB host stopped accepting connections on 27017 at
2026-11-16 ~21:10 EET. Ruled out from this machine:

- **not scheduling** — all three cron lines are present and every tick starts on time;
- **not a local store** — Laskin's own `mongod` is up, unchanged since 2026-09-08, but the AI26
  credentials fail authentication against it (`Authentication failed`, code 18): it is a
  different instance, so there is no local fallback to repoint at;
- **not general networking** — other ports on the *same* remote host answer from here (the
  shared Redis port accepts connections, the dashboard ingress returns 200); only 27017
  returns an immediate reset, i.e. nothing is listening there;
- **not a code regression** — contract checks pass in all three public modules;
- **not fixable from here** — the host's SSH port is open but key auth for the Laskin user is
  denied, so the service cannot be inspected or restarted from this machine.
