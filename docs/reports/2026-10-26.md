The tracked plan disables it (commit 634f439, the #347 fix, merged 2026-10-25 16:36); the deployed copy still has it enabled. Active counts: 102 tracked, 103 deployed.

That makes it an approval decision, not a maintenance action, so it was not deployed here. Tracked as issue #359 in Data-Collection with the exact commands and evidence.

A check that is permanently red for a legitimate reason is a check nobody reads; #359 asks whether it should compare identity sets instead of raw bytes.
