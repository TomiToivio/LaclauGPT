A check that is permanently red for a legitimate reason is a check nobody reads; #359 asks whether it should compare identity sets instead of raw bytes.
- The code halves of the drift are benign: Analysis is 2 commits behind (docs only) and Collection 9 commits behind (offline arena-backfill tooling, tests and docs). Neither changes hourly behaviour, and refreshing a live checkout is a release-gate step, so both were deliberately left alone rather than fast-forwarded during a running cycle.
